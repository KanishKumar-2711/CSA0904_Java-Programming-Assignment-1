## Project Description
This project focuses on designing and implementing an object-oriented Campus Smart-Parking System using Java.

The system manages parking slots across multiple floors, supports different vehicle categories, allocates parking slots, generates parking tickets, calculates parking fees, and releases slots when vehicles exit.
